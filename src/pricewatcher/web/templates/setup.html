Authentication Setup Required

PriceWatcher is locked (503 Service Unavailable) because no administrator password hash is configured.

Generate a scrypt password hash using the CLI:

pricewatcher hash-password

Then configure the environment and restart the server:

PRICEWATCHER_ADMIN_PASSWORD_HASH=scrypt:16384:8:1:...
PRICEWATCHER_SESSION_SECRET=replace-with-random-32-byte-secret

For isolated local testing without login, set PRICEWATCHER_INSECURE_NO_AUTH=1 explicitly.
