# Changelog

All notable changes to PriceWatcher are documented in this file.

## [Unreleased] - Security, Performance & Supply-Chain Hardening

### Security (`S1`–`S10`)
- **Personal Data & Repo Hygiene (Phase 0):** Removed personal phone numbers, email addresses, and watch YAML files from tracked git history; added sanitized [config/settings.example.yaml](config/settings.example.yaml) and [config/watches/example-watch.yaml.example](config/watches/example-watch.yaml.example) with automatic fallback in `ConfigStore.load_settings()`; made Reddit `User-Agent` contact URL configurable via `PRICEWATCHER_CONTACT_URL`.
- **Single-Admin Authentication (`S1`):** Added stdlib `scrypt` password hashing (`pricewatcher hash-password` / `--hash-password`), `PRICEWATCHER_ADMIN_PASSWORD_HASH`, fail-closed HTTP `503` setup screen when unconfigured, explicit `PRICEWATCHER_INSECURE_NO_AUTH=1` local dev toggle, HMAC-signed `HttpOnly; SameSite=Strict` session cookies (`PRICEWATCHER_SESSION_SECRET`), optional `PRICEWATCHER_COOKIE_SECURE`, and 5-attempt / 15-minute login rate limiting in [src/pricewatcher/web/auth.py](src/pricewatcher/web/auth.py).
- **SSRF & DNS Rebinding Protection (`S2`):** Replaced per-call clients with SSRF-validated outbound networking in [src/pricewatcher/http_client.py](src/pricewatcher/http_client.py) blocking non-HTTP(S) schemes, embedded credentials, zone IDs, and private/loopback/link-local/CGNAT/reserved/multicast/site-local IPv4 & IPv6 targets (unless listed in `PRICEWATCHER_ALLOW_PRIVATE_HOSTS`), pinning validated TCP IPs per hostname via `_PinnedAnyIOBackend`, isolating cross-host cookies, manually validating up to 5 redirect hops, intercepting Playwright requests through `polite_get()` + `route.fulfill()`, enforcing SSRF checks on `/api/probe` & `/api/source-packs/test-source`, and filtering ingested listing URLs across all adapters.
- **XSS & Strict CSP (`S3`):** Added `safe_url` template filter and `safeUrl()` JS helper; removed all inline `<script>`, `style=`, `.style.`, and `innerHTML` usage across templates and [app.js](src/pricewatcher/web/static/app.js); moved pre-render theme logic to [theme.js](src/pricewatcher/web/static/theme.js); enabled strict `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`, and `Cache-Control: no-store`.
- **CSRF Protection (`S4`):** Enforced `Origin`/`Referer` host checks and session-bound double-submit `X-CSRF-Token` / `csrf_token` validation on all `POST`/`PUT`/`DELETE`/`PATCH` requests including `/login`, `/logout`, HTML forms, and `/api/*`.
- **Safe Default Bind Host (`S5`):** Changed CLI `--host` default in [src/pricewatcher/main.py](src/pricewatcher/main.py) from `0.0.0.0` to `127.0.0.1` while keeping `--host 0.0.0.0` explicitly in container `CMD`.
- **Container Hardening (`S6`):** Updated [Dockerfile](Dockerfile) to digest-pinned `python:3.14-slim-bookworm`, startup volume ownership preparation with privilege drop to non-root `appuser` (`uid 10001`, `PUID`/`PGID`), `--no-deps` installation, and `/healthz` `HEALTHCHECK`; dropped `platform: linux/amd64` from [docker-compose.yml](docker-compose.yml).
- **Supply Chain & CI Gates (`S7`):** Added [requirements.lock](requirements.lock) for pinned runtime installs; updated [.github/workflows/docker-publish.yml](.github/workflows/docker-publish.yml) with 40-char SHA-pinned Actions, least-privilege per-job permissions, `ruff check`, `ruff format --check`, `mypy src`, `pip-audit`, and `pytest` gates prior to image build/push.
- **Error Hygiene & Payload Validation (`S8`):** Sanitized unhandled `500` server error responses and validated JSON object payloads across API routes in [src/pricewatcher/web/router.py](src/pricewatcher/web/router.py).
- **ReDoS Protection (`S9`):** Enforced 256-character max length on extractor patterns in [src/pricewatcher/config.py](src/pricewatcher/config.py) and switched extractor matching in [src/pricewatcher/matcher.py](src/pricewatcher/matcher.py) to `regex` with `timeout=0.05`.
- **Notifier Credential Hardening (`S10`):** Set `follow_redirects=False` and validated WAHA base URLs in [src/pricewatcher/notifiers/waha.py](src/pricewatcher/notifiers/waha.py); scrubbed `X-Api-Key` and SMTP credentials (`SMTP_USER`/`SMTP_PASS`) from logs and stored errors across [waha.py](src/pricewatcher/notifiers/waha.py) and [email.py](src/pricewatcher/notifiers/email.py).

### Performance & Reliability (`P1`–`P6`)
- **SQLite Observation Dedup & Retention (`P1`, `C6`):** Added schema v2 migration (`last_seen_at`, `idx_observations_dedup`), `Database.upsert_observation()` deduplicating unchanged price/stock tuples within 24 hours, and `Database.prune_old_observations()` scheduled daily using `server.retention_days` (default `180`).
- **Bounded Concurrency & Independent Watch Scheduling (`P2`):** Converted source fetching inside `PollEngine.poll_watch()` to bounded `asyncio.gather` (`server.fetch_concurrency`, default `4`) and refactored `scheduler_loop()` in [src/pricewatcher/main.py](src/pricewatcher/main.py) to run independent per-watch tasks.
- **Shared HTTP/1.1 Connection Pool & Size Cap (`P3`, `C2`, `C8`):** Added `HttpContext` with pooled `httpx.AsyncClient(max_connections=20, max_keepalive_connections=10)`, `1.5s` default (`2.0s` Reddit) per-domain politeness delays, and streaming `PRICEWATCHER_MAX_RESPONSE_BYTES` (default 5 MiB) truncation/abort.
- **Transaction Batching, Mtime Cache & Offloading (`P4`):** Added `Database.transaction()` batching per watch poll cycle, nanosecond mtime+size caching in `ConfigStore`, and `asyncio.to_thread()` wrappers on async hot paths.
- **Per-Watch Poll Locks (`P5`):** Added `PollEngine._watch_locks` returning `already_running=True` to prevent overlapping scheduler and manual poll runs from duplicating alerts.
- **Batched Dashboard Summary (`P6`):** Added `Database.get_dashboard_summary()` and wired `GET /` to fetch runtime, tier states, 7-day sparklines, source health, and alerts via batched queries.

### Audit Remediation (`M1`–`M5`, `L1`–`L9`)
- **Trusted Proxy & Deployment Hardening (`M1`, `M2`, `L3`):** Added `PRICEWATCHER_TRUSTED_PROXIES` (default empty/none) to gate both `X-Forwarded-For` client IP resolution (and uvicorn `proxy_headers` / `forwarded_allow_ips`) and `X-Forwarded-Proto: https` cookie `Secure` detection; bound [docker-compose.yml](docker-compose.yml) host port to `127.0.0.1:8080:8080` and defaulted `PRICEWATCHER_COOKIE_SECURE=1` in compose and [.env.example](.env.example).
- **Concurrency & Event-Loop Offloading (`M3`, `M4`):** Added lock-scoped `ConfigStore.update_settings()` and `ConfigStore.update_watch()` (plus lock-guarded `sync_builtin_source_packs()`) and routed all read-modify-write API handlers through them; offloaded remaining synchronous `store.*` and pack I/O in async routes via `asyncio.to_thread()` and simplified `GET /healthz` to lightweight `{"status": "ok"}`.
- **SQLite Indexing & Tuning (`M5`, `L5`):** Normalized timestamps to canonical UTC ISO-8601 (`+00:00`), added `idx_obs_watch_seen` expression index on `observations(watch_id, COALESCE(last_seen_at, observed_at))`, replaced `julianday(...)` range filters with indexed string comparisons, and enabled `PRAGMA synchronous=NORMAL` alongside `WAL`.
- **Container & Supply-Chain Hardening (`L1`, `L6`):** Switched [Dockerfile](Dockerfile) to start as non-root `USER 10001` (`appuser`), clarified the root-fallback privilege drop comment, pinned Playwright dependencies in [requirements-playwright.lock](requirements-playwright.lock) (`--no-deps`), and added CI lockfile freshness + `pip check` verification in [docker-publish.yml](.github/workflows/docker-publish.yml).
- **Session Revocation & Bounded Rate Limiting (`L2`, `L4`):** Added expiry-pruned server-side session revocation on `POST /logout` (with `PRICEWATCHER_SESSION_SECRET` rotation documented for global logout) and periodic expiry sweeps + `max_keys=4096` LRU bound on `LoginRateLimiter`.
- **Quality, Test Coverage & Modularization (`L7`, `L8`, `L9`):** Extracted `_describe_missing_session()` with redacted `DEBUG` logging in [src/pricewatcher/notifiers/waha.py](src/pricewatcher/notifiers/waha.py); added [tests/test_notifiers.py](tests/test_notifiers.py), [tests/test_discovery.py](tests/test_discovery.py), expanded [tests/test_http_client.py](tests/test_http_client.py), and scheduler error tests; split [src/pricewatcher/web/router.py](src/pricewatcher/web/router.py) into [src/pricewatcher/web/routes/](src/pricewatcher/web/routes/__init__.py) sub-routers and [src/pricewatcher/web/static/app.js](src/pricewatcher/web/static/app.js) into ES modules (`utils.js`, `ui.js`, `manage.js`, `settings.js`, `app.js`). (`L10` free-text search profiled at ~3.2 ms across 10k rows via `idx_obs_watch_seen`; FTS5 deferred.)
